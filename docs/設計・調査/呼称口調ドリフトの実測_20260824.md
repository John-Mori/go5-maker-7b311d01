## 3. 真因(実装を読んで特定)

### ① `naming_gate.py` の人事部門オフ(2026-08-03 A案)→ 呼びかけ位置だけ直すへ(2026-08-24)

人事部門**だけ**本文の自動修正を止め、全部 warning へ落としていた。
結果として**呼称の正本を持つ部屋の発言だけが崩れたままChamiに届く**。ククール1人で28件。

人事部門(ククール)から「引用マスクがあるから全面復帰してくれ」と依頼(msg 1541253031553798294)。
**実物で測って、そのままは呑まなかった。**

母集団= `naming_audit.jsonl` の hr-room 漏れ**90本**。自動修正を当て直すと:

| | 書き換わる箇所 | うち化け |
|---|---|---|
| 全面復帰(依頼どおり) | **46** | **30** |
| 呼びかけ位置だけ(採用) | **7** | **0** |

化けの正体は引用符ではない。人事部門は人格名を**呼びかけでなくデータ**として書く:

1. **名簿の列挙**= 「常体8人格(デブライネ/モドリッチ/ククール/オタコン/**三笘**/星南/…)」→ 三笘さん
2. **設定オブジェクトの持ち主**= 「口調ルール.jsonの**三笘**のforbiddenへ1語追加した」→ 三笘さんのforbidden
3. **判定対象の識別子**= 「同じ文を**アロンソ**で判定しても空」→ アロンソコーチで判定

最悪例(実物)= 「呼称ルール.json にも三笘→三笘の自己言及ルール(allowed=俺・**三笘** / forbidden=三笘さん)」
→ 「(allowed=俺・**三笘さん** / forbidden=三笘さん)」= **記述しているルールを反転させる。**
どれも引用符が付かない=`_mask_quoted_mentions` では1つも防げない。

**採用した形**= `VOCATIVE_ONLY_DEPTS = {"hr-room"}`(commit `b589a7f`)。
呼びかけ位置=①出現が**行頭**から始まり ②**直後が読点**、の2条件が揃う所だけ直す。
列挙・設定キー・識別子はこの形にならないので**機構で外れる**(心がけではない)。
GOLDEN F-16〜F-19 追加(70件PASS)・must-fail=`_is_vocative` を「全部呼びかけ扱い」へ
差し替えると F-14/16/17/19 が赤。

★**本番の実便で裏取り(2026-08-24 10:25)**= 人事部門から届いた便(`DISPATCH-aegis-gl-1787534725165` の 2/2)を
本物の `naming_corrections()` に通した。**全面復帰の設定だと1行が化ける**:

> ・人格名を"データ"として書く時=素の名前のまま=(a)『/』区切りの名簿列挙 (b)設定オブジェクトの持ち主・キー(口調ルール.jsonの**三笘**のforbidden) (c)判定対象の識別子(**三笘**で判定しても空)

★A案の当時の説明「autofixが『三笘くん』→『三笘さん』へ化けさせた」の**向きは裏が取れない**

### ② 同 L655 の startswith 制約

```python
target_form = allowed[0]
if not target_form.startswith(bare):
    result["remaining"].append(v)   # 直さず警告のみ
```

置換先が「出た形」で始まる時しか直さない。だから「アロンソ→アロンソコーチ」は直るが
**「一ノ瀬」→「怜」は直せない**。

★これは**バグではない**。L530-541 に設計として明記されている=自動修正は 2026-07-31 に
Chamiへ提案して「いいよ」で承認された2型に限る、安全弁として「別名・愛称への丸ごと置換はしない」。
**黙って外すと承認範囲の無断拡大になる。**

当て所は2つ:
1. **生成側に書く**(人事部門)= characterfile に「一ノ瀬怜は『怜』と呼ぶ」。後から直すより間違えない方が正しい。
2. **Chamiに範囲拡大を諮る**= 「別名への丸ごと置換も自動修正してよいか」。誤検知時の被害が増える。

## 5. 測り方の教訓

- **送信済み本文にゲートを当てるな。**`audit_tone`/`naming_corrections` が既に直しているので鳴らないのは当たり前。
  当てるべきは**生成原文**(§1の母集団)。

- **0%と100%が出たら、まず自分の当て方を疑う。**
