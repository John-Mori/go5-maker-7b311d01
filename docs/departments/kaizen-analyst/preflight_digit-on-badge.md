> 起票= 改善提案部門(トトリ/アスナ)・2026-08-14。渡す先= 改修部門α(system-engineer)。
> 由来= 分類器 `scripts/kaizen/daily_repair_analysis.py` の2クラスタ
> 「販促ラベル/セール札/割引表示」17件 +「ランキング/順位表示」15件(90日窓・commit実測)。
> ★これは**型(仕様)**であって実装コードではない。**5秒動画メーカー本体へ書くのは改修部門α**(C-015)。

## 0. 数字で見た「本当の再発の芯」(盛らない)

32件そのものは同じ再発ではない。change_log を全文で読み直すと、**再発の芯は1つの作成メカニズム穴**に集まる=
**「数字を装飾された面(セール札PNG / 順位バッジ)の上に載せる時、位置・サイズ・色・コントラストが一発で決まらず、目視で何度も微調整して再依頼になる」**。

実測(commit連番が「同じ物の見た目を詰め直している」証拠)=

- **販促ラベル 数字slot の往復 ≈ 9件**(8/10〜8/11に集中):
  `26e9f66 → df8afcd → dee461b → e4a0f78 → ff97b3e → 306e47b → 1ca74a3 → ad0559e → 4949c75`。
  中身は全部「¥の数字の slot(x/y/w/h)を素材PNGへ合わせ直す」「インク色を素材へ合わせ直す」。
  さらに `d53b086(reveal即時化)→ 69fb67a(ロールバック)` の往復1件。
- **ランキング順位番号 見た目の往復 ≈ 6件**(8/2に集中):
  `bf9f234(箱)→ eef574a(text-strokeへ戻す)→ 204f050(paint-order)→ b333213(SVGフィルタ)→ 2a668d0(書体Graduate)→ 9f9a92a(既定書体へ戻す)`。
  縁取り/書体/箱を行ったり来たり=**基準が凍っていないから毎回やり直す**。

→ **プリフライトで止められるのはこの約15件**。残り約17件は新機能(ワースト20モード・両ch シート合算・%オフ/円分岐・総集編/定価の自動反映など)=**A健全な往復であってプリフライトの対象ではない**。ここを混ぜて「32件が再発」と言わない。

## 1. 型(改修部門αが作成経路へ差し込むプリフライト)

**発火点**= 「数字を装飾面へ焼く/重ねる描画」を作る/差し替える時(`drawDigits` 系・セール札・順位番号の描画を触る commit の直前)。
**やること**= 下の5点を**自動で1回検査**し、外れたら**作成を止める(または警告を出す)**。目視の往復を機械の検査に置き換えるのが狙い。

| # | 検査 | 何を防ぐ | 実測の裏 |
|---|---|---|---|
| P1 | slot(x/y/w/h)は**素材PNGの画素解析(ink-box検出)で導出**する。手打ちの定数を単独で採用しない | slot を目分量で置いて毎回ズレる | `26e9f66`〜`4949c75` の連続再測 |
| P2 | 数字の縦横中央合わせは**bounding box でなく ink-box(字面)中心**で取る | ¥や飾り罫に対して数字が上下にズレる | `ff97b3e`(ink box中心へ変更)/`e4a0f78`(中心線寄せ) |
| P3 | **コントラスト比を測る**=数字インクの輝度 vs 直下の局所背景の輝度。閾値未満なら**濃色輪郭+弱い落ち影を自動付与** | 明るい札で数字が霞む | `8e78d42`(濃色輪郭+落ち影で解決した実例を一般化) |
| P4 | **アカウント別テンプレを各々検査**(acc1 月詠み / acc2 宵桜)。インク色・素材が別なので**片方の合格を両方の合格にしない** | 片chで合わせたら他chで崩れる | `1ca74a3`/`ad0559e`/`306e47b`(acc2側を別途合わせ直した) |
| P5 | **ゴールデン画像スナップショット**を1枚持ち、slot定数や色を変えたら**差分が出る**ようにする。順位番号の見た目は**正準を1つ凍結**(paint-order:stroke fill / Noto Sans JP既定 / 白字+黒フチ 2px)し、そこから外れる変更は差分で気づく | 見た目が行ったり来たりして版だけ増える | `bf9f234↔eef574a↔9f9a92a` の振動 |

---

## 2. 受け入れ条件(改修部門αが「効いた」と言える基準)

- P1〜P4 が作成経路に入り、**手打ち slot 定数だけの差し替え commit が発生しなくなる**(次にセール札/順位番号を触る時、まず ink-box 実測とコントラスト検査を通る)。
- P5 のゴールデン画像がリポジトリにあり、slot/色/書体を変える PR で**視覚差分が見える**。
- ★確認は §4.55 準拠=「入れた(確認待ち)」→ 次に販促ラベル or 順位番号を触る回で**実物(生成された札/順位バッジ)を1つ見て**初めて「効いた」。

## 3. Check(改善提案部門が測る)

- 指標= 分類器の「販促ラベル」「ランキング」クラスタのうち、**同一素材の位置/色/コントラストの微調整 commit**の週次本数。
- ベースライン= 8/2(順位番号6件)・8/10〜11(販促9件)の**バースト**。
- 目標= プリフライト投入後、同型バーストが**0**になること。測り直し日= 2026-08-20(木)。

## 4. 型の外(混ぜない)

- 割引ロジック(%オフ/円分岐・二段階四捨五入・総集編/定価の自動反映・99円切替)= **仕様の新規実装**。プリフライトの対象外。
- ワースト20・両ch シート合算・競合分析ランキング= **新機能**。対象外。
- これらを「再発」に数えない(Z1 の A健全)。
