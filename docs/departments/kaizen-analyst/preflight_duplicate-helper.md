## 何を止めるか(1行)
**同じ判断関数(自前ドメイン判定・終端処理・フォールバック分岐など)を同一ファイル内や複数ファイルへコピーすると、後で片方だけ直したときにもう片方が古いまま残り、静かに挙動が割れる。** バグは「直したのに再発」の形で出る(直した先が使われていない)。

## 実測した再発(=この型が要る証拠)
- **生きた乖離が今のコードに在る**= `js/yt-clicks.js` の `function isR2(u)` が **4定義・2変種**:
  - `1560` / `1598` = `go5.ourBase(u)` の同文
  - `3427` / `3487` = `go5.ourBase ? … : (u.indexOf(workerUrl…))` の**フォールバック分岐が違う別実装**
  → `go5.ourBase` を直しても、旧フォールバックを持つ 3427/3487 側は別の答えを返しうる。
- **同型のインシデント**(インシデント.md)= INC-112(短縮ホスト一覧が複数ファイルに複製→GAS側の取り残しでクリック計測が全滅。「一覧を増やす時は全複製箇所を洗うか単一の出典にまとめる」と明記)/ INC-134(同一ファイル内の関数二重定義で改善版が後の定義に上書きされた)/ INC-140(「同じ判断・終端・フォールバックを複数箇所にコピーしない」)。

## 不変条件(守れているか機械で見る)
- **I1**: 同一ファイル内に、同名 `function` を**中身違いで2つ以上**定義しない(定義は1つ、必要なら引数で分岐)。
- **I2**: 判断・終端・フォールバックを**複数ファイルへコピーしない**。共有するなら `core/` の1関数へ出典を寄せる(INC-112/140 の教訓)。
- **I3**: どうしても複製が要るなら、**全複製箇所を洗える一覧**(コメント or 登録簿)を持ち、片方直したら残りも同じコミットで直す。

## 機械で止める案(改修αへ渡す検査の下書き)
grep一発ではなく**小スクリプト1本**(CI門3兄弟と同じ smoke 相乗り):
```bash
# 同一ファイル内で同名 function が2回以上定義され、本文(正規化後)が一致しないなら赤。
#   → js/*.js を走査し {ファイル, 関数名, 本文ハッシュ} を集計、
#     同名×本文ハッシュ2種以上 = 乖離コピー = 赤。
# 現在の重複(12名・目視確認済)はホワイトリスト凍結し、新規の乖離コピーだけを弾く=回帰ゼロ。
```
検査の芯= **「同名なのに中身が割れているコピーが新規に増えたら赤」**。

## 直し方の定型(ヘルパを書く人がやること)
1. 既に同名関数が在るなら、**新規にコピーせず既存を呼ぶ**(引数で差分を吸収)。
2. 複数ファイルで要るなら `core/` へ出し、各所は**それを import/参照**する。
3. 複製が避けられないなら、**全箇所へ同じコミットで**同じ変更を当てる(片側だけ直さない)。
