# 日次レポート様式(Chami向け・トピック別)

> 出典: Chami指示 2026-08-22「分析の書き方が分かりにくい。トピックごとに」。
> 対象= 分析部門chからChamiへ出す**毎日の振り返り便**。部門間・HQ宛の技術報告は従来の `報告様式.md`(結論→観測→仮説→次)を使う=**混ぜない**。

## 大原則
- **専門用語を表に出さない。** z平均・Mann-Whitney・Spearman等の統計語は**言葉の結論だけ**を書き、数式・p値は台帳(competitor_daily/・hypotheses.md)へ。Chamiが根拠を欲したら台帳のパスを1行で示す。
- **各トピックは「ひとことまとめ」から始める。** 数字の羅列で始めない。
- **数字は「意味」と対で書く。**「wv=1264」でなく「1,264回=平凡ライン」。
- 全体で**画面1枚(20行前後)**。深掘りは台帳へ。

## トピックの順(この3本＋必要な時だけ次の一手)

### ① 昨日の投稿はどうだったか
- **ひとことまとめ**(勝った/平凡/不発)。
- **数字**: 本数 / 一番伸びた1本(タイトル＋再生) / 一番ダメだった1本 / 平均的な伸び。
- **効いた・効かなかった**を1〜2点(型・時刻・作品のどれか)。★再生(wv)で語る。クリック(cc/cwc)と混同しない。

### ② 競合はどうだったか
- **ひとことまとめ**(今日の勝ち型/負け型)。
- **勝ち型・負け型**を各1〜2点(言葉で)。
- **気になった1本**(あれば・題名と何が効いたか)。
- ★データが古い時は「◯/◯で止まっている(新規なし)」と正直に書く。

### ③ 新しい情報 / 仮説の動き
- 確定したこと / まだ様子見のこと を各1点。
- コピー部・商品部へ渡した/渡す知見があれば1行。

### (④ 次の一手 ※Chamiの手番がある時だけ)
- Chamiが決める1事(投稿時刻・作品・文言)に絞る。手番が無ければ**書かない**。

## 語彙の言い換え表(表に出す時)
| 内部語 | 表に出す言葉 |
|---|---|
| wv(週再生) | 再生(回) |
| 速度中央値 | 平均的な伸び / 標準的な1本 |
| 断定形/問いかけ形 | 言い切り/？で終わる |
| チャンネル補正z | 「そのchの地力を差し引くと」 |
| 有意でない | 「差はブレの範囲=当てにしない」 |
| 固有数字型 | 具体的な数字(歳・回・円・番) |
| 曖昧数量煽り | ○選・たった○週間などのフワッと数字 |
