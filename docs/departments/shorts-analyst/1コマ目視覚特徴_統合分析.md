## 3. 読み(なぜ)
- **不可読(多コマ密)が最強の負けシグナル**: #06/#10/#13 は3コマ以上の細かい割りで1コマが小さく、サムネ縮小時に"何のシーンか"が0.5秒で伝わらない→テスト配信で即スワイプ→増幅停止=wv3。
- **カラー×可読×絵の意外性**の3つ揃いがブレイク圏(#00〜#02=ボタンパネル/×グリッド/ビフォーアフター)。絵単体で"意外な状況"が完結している。
- **カラーでも不発(#08/#12)**=カラーは必要条件的だが十分でない。絵の意外性が無い平凡な日常シーンは題名で問い返しても伸びない(SA-H005と整合)。
- **順序**: ①0.5秒可読(多コマにしない・カラー) → ②絵で意外性を完結 → ③題名は断定形で意外な結末(SA-H005)。露出はこの順序に対して主変数ではない(規約上は電車内基準を守るが、再生の主因ではない)。

## 4. 限界
