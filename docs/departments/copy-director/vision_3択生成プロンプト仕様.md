用途: 改修αのvision実装が、候補作品の挿入画像を読んで従来型コメントを **各3択** 自動生成するための型。正本=このファイル。ガードレールの根拠正本=copy-rules.md / winning-patterns.md / rejected-patterns.md。

## 0. 何を生成するか(1行)

候補の挿入画像(フルカラー前提)を読み、**あらすじ(product-scoutがスクレイプ取得)で文脈を補完**したうえで、その **絵に最も合う** コメント(動画の大タイトル=フック)を、狙いの違う3案で出す。判断軸は常に **利益最大化**(ch別ボイス分けはしない=copy-director-no-voice-split)。

★**あらすじの立ち位置(2026-08-23 Chami指示・改修α経由 DISPATCH-copy-director-1540962015047061524)**=あらすじは **理解のための材料であって、題名に写す素材ではない**。Chami原文「あらすじ表示はいらんけど、スクレイピングで取得して内容考慮して決めてくれたら嬉しい」。→ **表示しない/取得して内容を考慮する**。用途は §1.5。

## 1. 3案の振り分け(★この3枠を必ず埋める)

3案は「同じ絵に対する角度違い」であって「良い順3つ」ではない。各枠に狙い(aim)を固定する。**水木金評価(local/_work/eval_水木金_2026-08-19_21_軍議.md)=「再生は取れているがクリックが栓」**を受け、**枠2を必ず"クリックを取りに行く"振りにする**。

| 枠 | aim(狙い) | 主に使う型 | 何を取りに行くか |
|---|---|---|---|
| 案1 | **感情(自己投影)** | ⑥自己投影 / ⑧セリフ増幅 | 視聴者が自分を重ねる感情の芯。フィード通過後の視聴維持=再生 |
| 案2 | **謎・続き示唆(クリック誘引)** | ④視点転換 / ②時間差 | "何かが起きた"と断定し中身だけ伏せる=続きが気になる→リンクへ(=クリック) |
| 案3 | **意外・常識破壊** | ⑤常識破壊 / ④視点転換 | 絵の設定に反する言い切りのギャップで引く |

★**枠2(クリック誘引)の作り方が肝**=「続きは」「概要欄」等の直接誘導語は**規約違反=禁句**(§3)。だから **okada③=続き示唆/変化予告断定型**で作る=「〜に異変が起きた」「〜が消えなかった」「〜が最後だった」のように **"起きた"を断定しつつ中身(何が)だけ伏せる**。競合の速度TOP5が全部この型(copy-rules該当行)。隠し問い(どう〜?/〜と思う?)は逆に弱い(SA-H005・？型は当てにしない)ので使わない。
★★注記(軍議・分析へ)=水木金評価では**真のクリック漏れはYouTube→説明/固定→X→FANZAの導線(構造)**で、コピー単独では埋まらないと出ている。枠2は"続きが気になる"の最大化まで=導線の穴埋めは改修α/分析の範囲。コピーは規約内で好奇のギャップを最大化する所までやる。

## 1.5 あらすじの使い方(★内容は考慮する・題名には写さない)

あらすじは **絵だけでは読めない事実** を補い、外さない題名を作るために使う。**題名の言葉はあくまで"電車内基準で見える絵のSFWレイヤー"から採る**——あらすじは判断の裏付けであって、あらすじの語をそのまま題名に出さない。

**あらすじで拾ってよい(=題名の判断に効かせる)**:
1. **関係の確定**=彼女/元カノ/嫁/妹/幼馴染/上司…絵では見分けられない関係を確定させ、関係語の誤用(rejected「どっちが彼女だと思う?」)を防ぐ。読めれば正しい関係語が使え、フックが鋭くなる。
2. **加害/被害の構図**=誰が仕掛け誰が受けか。断罪・落差型の主語を取り違えない(rejected「奥さん、詰みです」)。あらすじで構図が確定して初めて断罪コピーを許可。
3. **感情の芯(⑥自己投影/⑧セリフ増幅の弾)**=劣等感・喪失・裏切り・一途…主人公の内面の動機。絵が内面を描かない構図でも、あらすじで芯を掴み、それを**絵の可視要素に宿らせる**(例「またねの相手は僕じゃない」)。
4. **"何が起きたか"の変化点(案2の弾)**=あらすじの転換(関係が壊れる/裏の顔が出る/立場が逆転)を掴み、**中身は伏せたまま"起きた"だけ断定**する(okada③)。あらすじがあるほど案2の続き示唆が具体的で強くなる。
5. **意外・常識破壊の落差(案3の弾)**=あらすじ上の設定(清楚/軽い/強気…)と実際の行動のギャップを見つける。

**あらすじから題名へ絶対に持ち込まない(§3再掲・最優先)**:
- 性行為・露骨な性的単語・暴力・露出。あらすじがそれ主体でも、題名は抽象語(喪失感・一途・裏の顔・執着 等)で止める。**あらすじの過激さ=題名の過激さ、にしない。**
- 作中の実名(人物名)。役割語/属性語へ。
- あらすじにしか無く**絵に映っていない性/露出の状況**を指す語(「バックヤードで何?」型)。絵で見えない過激は書かない。

★要するに=**あらすじは"どう解釈するか"を正すために全部読む。題名に出すのは絵のSFWレイヤーだけ。** あらすじが無い候補は従来どおり絵のみで生成(あらすじは補強材で必須依存にしない=取得失敗しても3択は出す)。

## 2. 全案に共通で効かせるルール(生成時の必須チェック)

1. **断定主軸**(SA-H005)=言い切る。？型は3案で**最大1つ**、原則0。隠し問い(結末を隠して問う)は避ける。
2. **拍子を散らす**(C-038)=読点2分割「〇〇、〇〇」は3案で**最大1つ**。残りは読点なしの一息・短い宣言・体言止め等でリズムを変える。全案同じ拍子にしない。
3. **絵内の吹き出しをなぞらない**=視聴者は吹き出しを読める。絵が言っていない**新しい層**(外からのツッコミ・状況の言語化・視聴者の代弁・意外な切り口)を足す。⑧セリフ増幅を使う時も語順/語尾を変えて丸パクリを避ける。
4. **字数**=1行は**10字まで縮小なし**(app.js:276-283)。10字を超えるなら **2行モード**(各行10字前後を狙う・改行位置を明示)。目安10〜18字。長すぎは自動縮小で視認性が落ちる。
5. **加害/被害の構図を絵の設定通りに**=断罪・落差コピーは"誰が加害で誰が被害か"を取り違えない(rejected「奥さん、詰みです」の誤り)。設定が読めない時は断罪の主体を決めつけない。
6. **関係語(彼女/嫁/元カノ/妹等)は絵で関係が成立している時だけ使う**(rejected「どっちが彼女だと思う?」)。成立が読めなければ状態語(相手/会う人)に置き換える。
7. **数字**=絵の事実の固有数字(年齢・人数・金額・順位=③固有数字型)は**使ってよい**(武器)。年月ジャンプ数字(5年後/たった○週間/○ヶ月で=経過スパン型)と数量煽り(○選/○個)は**避ける**。
8. **落差型は背景の派手さに頼らない**(コピー側の助言であって画像選定=product-scout範囲。生成文には出さない)。

## 3. 規約防衛(P0・違反=チャンネル凍結=全施策が無に帰す/★1つでも破ったら不合格)

- **煽り禁句**を使わない=「続きは」「概要欄」「見せられない」等の直接誘導語。**枠2も禁句なしで作る**(断定+伏せで代替)。
- **あらすじの性・暴力を題名で一切指さない**=絵が全着衣・露出ゼロ(電車内基準)なら、題名も抽象語(喪失感・一途・裏の顔 等)で止める。性行為・露骨語・「バックヤードで何?」型の増幅は禁止。伏せ字はvisionが外さない。
- **実名を題名に出さない**=作中の人物名(キャラ名)は使わない。「ギャル」「委員長」等の**役割語/属性語**に置き換える。
- **半角括弧 `()`**(全角 `()` 禁止)。ハッシュタグを本文に混ぜない(④は題名兼用だが定型タグは描画から自動除去=題名文には書かない)。
- **2ch同一文言禁止**は投稿運用側(同じ文言を月詠み/宵桜へ使い回さない)。生成は画像ごとに最適文=同型量産にしない。

## 4. vision へ渡すプロンプト本文(改修αはこれをそのまま使う)

> 入力=候補1件の挿入画像(複数可・フルカラー前提)＋あらすじ(取得できた時。取得失敗なら絵のみ)＋任意でタイトル。出力=下のJSONのみ。

```
あなたは日本のYouTube Shorts(FANZA作品紹介・縦型5秒動画)のコピーライターだ。
渡された挿入画像(フルカラー)を読み、その動画の大タイトル(コメント=フック)を
「狙いの違う3案」で作れ。判断軸は常に「クリックと成約=利益の最大化」。

【絵とあらすじの読み方】
- 絵に映っている人物の表情・仕草・関係性・その場の状況を読む。
- 絵の中の吹き出し(セリフ)は視聴者も読める。だから題名は吹き出しをなぞらず、
  絵が言っていない新しい層(外からのツッコミ/状況の言語化/視聴者の代弁/意外な切り口)を足す。
- あらすじが与えられたら、それは【解釈を正すための材料】として全部読む。使う所は:
  ①関係の確定(彼女/元カノ/嫁/妹/上司など。絵で見分けられない関係を確定する)
  ②加害・被害の構図(誰が仕掛け誰が受けか。断罪・落差の主語を取り違えない)
  ③主人公の感情の芯(劣等感/喪失/裏切り/一途など。⑥自己投影・⑧セリフ増幅の弾)
  ④"何が起きたか"の変化点(関係が壊れる/裏の顔が出る/立場が逆転。案2で中身を伏せて"起きた"だけ断定)
  ⑤設定と行動のギャップ(清楚/軽い/強気…と実際の落差。案3の弾)
- ★ただし【題名に出す言葉は、電車内で見せて困らない"絵に見えるSFWの層"だけ】。
  あらすじがどれだけ過激でも、題名はあらすじの過激さをなぞらない。
  性・露出・暴力はあらすじにあっても抽象語(喪失感/一途/裏の顔/執着 など)で止める。
  絵に映っていない性・露出の状況を指す語(「バックヤードで何?」型)は書かない。
  あらすじは"どう解釈するか"を正すためだけに読み、題名の素材にはしない。

【3案の枠(必ず3つとも別の狙いで埋める)】
案1 感情(自己投影): 視聴者が自分を重ねる感情の芯。型=⑥自己投影 か ⑧セリフ増幅。
案2 謎・続き示唆(クリック誘引): 「〜に異変が起きた」「〜が最後だった」のように
    "何かが起きた"と断定しつつ中身(何が)だけ伏せて、続きを気にさせる。型=④視点転換 か ②時間差。
案3 意外・常識破壊: 絵の設定に反する言い切りのギャップで引く。型=⑤常識破壊 か ④視点転換。

【全案の必須ルール】
- 言い切る(断定形)。「？」で終わる案は3つで最大1つ、なくてよい。
- 3案のリズムを変える。読点で2つに割る形(「〇〇、〇〇」)は3つで最大1つ。
- 1行は10字まで。超えるなら2行に分け、改行位置を「/」で示す(各行10字前後・2行でも合計20字まで)。
- ★3案のうち少なくとも1案は1行(10字以内)でスパッと言い切る=全案を2行にしない。短い案と2行案を混ぜてリズムを変える(Chami指示2026-08-24・選ぶ側が短い/長いを選べる)。
- 絵の事実の固有数字(年齢・人数・金額・順位)は使ってよい。
  年月ジャンプ(5年後/たった○週間で)と「○選/○個」の数量煽りは使わない。
- 断罪・落差の題名は、絵の設定で誰が加害・誰が被害かを取り違えない。
- 彼女/嫁/妹などの関係語は、絵でその関係が成立している時だけ使う。
  読めなければ「相手」「会う人」等に置き換える。

【絶対禁止(1つでも破ったら出し直し)】
- 「続きは」「概要欄」「見せられない」等の直接誘導語(案2も禁止=断定+伏せで作る)。
- 性行為・露骨な性的単語・暴力を指す語。絵が全着衣なら題名も抽象語で止める。
- 作中の人物名(実名)。役割語/属性語(ギャル・委員長・先輩 等)に置き換える。
- 全角括弧（）。使うなら半角()。

【出力(このJSONだけを返す。説明文を付けない)】
{
  "comments": [
    {"n":1, "aim":"感情", "type":"自己投影", "text":"題名(2行なら / で改行)", "chars":9, "two_line":false},
    {"n":2, "aim":"謎・続き示唆", "type":"視点転換", "text":"…", "chars":13, "two_line":true},
    {"n":3, "aim":"意外・常識破壊", "type":"常識破壊", "text":"…", "chars":10, "two_line":false}
  ]
}
```

★**schema注記(軍議の判断待ち)**=提案決定ページ設計書§2の候補JSONは `comments[]={"n","text"}` だけ。だが copy-rules は「各案に型①〜⑧を添える(学習資産化)」を必須にしている(Chami指示2026-07-31)。→ **`comments[]` に `aim`/`type`/`chars`/`two_line` を足すことを推奨**(描画は `text` だけ使えばよい・残りはメタデータでwinning-patternsの学習に使う)。`text` には題名だけを入れる(型や狙いを本文へ混ぜない=そのまま描画されるため)。schemaを凍結で `{"n","text"}` に固定するなら、型/狙いは提案ページのDB側で別に持つ設計を改修αと詰める。

## 5. 手本3択(型が伝わる見本・実候補が来るまでの雛形)

★実際にこの部屋でChami確定済みの作を、3枠構造に展開した見本。**枠1は確定文、枠2/枠3は同じ絵に別角度を当てた例。**

### 手本A: NTR図書委員長作(絵=茶髪の図書委員長が笑顔で手を振る「またねー」＋画面内キャプション「今から叡智をする委員長」/あらすじ=童貞主人公が片想いする委員長が別の男と…「僕が先に好きだったのに」)
- 案1 感情(⑥自己投影/④視点転換《除外》): **またねの相手は僕じゃない**(12字・2行[またねの相手は/僕じゃない]) ★Chami確定
  - 狙い=手を振る"またね"の行き先が僕ではない=先に好きだったのに奪われた芯を絵の仕草に重ねる。
- 案2 謎・続き示唆(④視点転換《変化予告断定》): **委員長のまたねが最後だった**(13字・2行[委員長のまたねが/最後だった])
  - 狙い="最後だった"と言い切り、何があったかは伏せる=続きが気になる。禁句なし。
- 案3 意外・常識破壊(⑤常識破壊《二面性》): **優しい委員長の裏の顔**(10字・1行)
  - 狙い=清楚な委員長像に反する「裏の顔」の言い切りでギャップ。
- 規約=全着衣・露出ゼロ・実名(人物名)なし・性描写を指さない=クリア。

### 手本B: ギャル一途別れ拒否作(絵=部屋で拓海が「別れたい」/ギャル莉空が涙目で「やだ」/あらすじ=劣等感で別れを切り出す彼氏を一途なギャルが拒む)
- 案1 感情(⑧セリフ増幅×⑤常識破壊《一途なギャル》): **絶対別れないと泣く一途なギャル**(15字・2行[絶対別れないと泣く/一途なギャル]) ★Chami確定
  - 狙い=ギャル=軽いの逆張りを題名内で自己完結(性質ラベル「一途な」を足し、意外な主語を2行目のオチへ)。
- 案2 謎・続き示唆(④視点転換《変化予告断定》): **振ったギャルが引かなかった**(13字・2行[振ったギャルが/引かなかった])
  - 狙い="引かなかった"と結果だけ断定し、どう食い下がったかは伏せる=続きが気になる。
- 案3 意外・常識破壊(⑤常識破壊《本気の逆転》): **ギャルの方が本気だった**(11字・2行[ギャルの方が/本気だった])
  - 狙い=軽い側と思われたギャルが本気=関係の温度差の逆転で引く。
- 規約=全着衣・涙目のみ・実名なし・肉体アプローチを指さない=クリア。

★実候補JSONが来たら、各候補の `images` に対しこの3枠で生成し `comments[]` を埋める。手本の枠1が確定文なのは実績照合用=生成時は3枠とも新規に作ってよい。

## 6. 受け入れ確認(改修αの実装が満たすべき点)

- 出力は必ず3案・各案に aim(3枠を1つずつ)。
- §2・§3を全案が通る(特に§3の禁句/実名/露出=1つでも破ったら不合格=再生成)。
- 案2は続き示唆(変化予告断定)で、直接誘導語を使わずクリック誘引になっている。
- 字数と2行判定が付く(10字超は two_line=true・改行位置つき)。
- 型①〜⑧が各案に付く(学習用メタ・§4のschema注記)。
