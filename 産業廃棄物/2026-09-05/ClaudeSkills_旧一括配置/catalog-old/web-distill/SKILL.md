# Webページの蒸留(読む前に本文だけへ)

## なぜ手順を固定するのか
サブエージェントやLLMが**生HTMLをそのまま読むと、nav/script/style/広告/装飾タグでトークンを大量に焼く**。
まとめ1記事の生HTMLは実測で **189,421B**。ここから本文(反応レス・コメント・テロップ候補)だけ抜くと **8,214B(-96%)** まで落ちた。読む中身は落ちない=**質を落とさずトークンだけ落とす**。
5ch風/VTuber反応集のネタ集めは「大量のまとめ記事・スレを読む」仕事=ここが一番トークンを焼くので、取得の入口で必ず蒸留を通す。

## 使い方(cwd=`D:\SougouStartFolder\5SecMovieMaker`)
```bash
python scripts/web_distill.py <URL> [<URL> ...]       # 蒸留して local/5ch_research/distilled/ へ保存
python scripts/web_distill.py --url-file urls.txt      # 1行1URL(# はコメント)
python scripts/web_distill.py <URL> --stdout           # ファイルに書かず標準出力へ
python scripts/web_distill.py <URL> --via-jina         # 文字化け/取得困難ページ(下記)
python scripts/web_distill.py --help
```
- 出力ファイルの先頭に **`bytes: raw=… -> distilled=… (-N%)`** が必ず入る。**この数値だけを削減率として報告する**(自分で見積もった率を書かない)。
- 連続取得は既定 **1.2秒間隔**(`--sleep` で調整)。★**同じサイトを短時間に連打しない**(取得先の作法)。
- **生HTMLを直読みしない**。まず蒸留し、蒸留後テキストを読む。これが手順の要。

## Shift_JIS/文字化けページ(5ch・したらば・古いまとめ)
`--via-jina` を付けると **r.jina.ai** プロキシ経由で整形済みテキストを取る(**読み取りのみ**・書き込みはしない)。
Shift_JIS直取得で文字化けする板・ページはこちらへ逃がす。

## 文字コードの罠(この道具が既に対処済み・触る時は壊すな)
- **単バイトコーデック(cp1251/windows-1251 等)は、どんなbytesでも strict デコードが"成功"してしまう**(例外を出さない)。だから chardet/apparent_encoding の誤ったキリル推定が"通って"しまい、日本語がキリル文字のゴミになる。
- 対策=**多バイト検証が効く `utf-8` → `cp932` → `euc-jp` の順で strict デコードを試す**。charset宣言も**日本語系(shift_jis/euc-jp/utf-8)だけ**信用し、cp1251等の宣言は無視する。`_decode()` を触る時はこの不変条件を壊すな。

## やらないこと(P0・規律)
- ★集めた生素材・蒸留物は **local/ 配下だけ**(既定=`local/5ch_research/distilled/`)。**公開repo・D1・外部サービス・Webへ出さない**。curated版のみ `D:\SougouStartFolder\5chShortMovie\リサーチ\` へ。
- ★**P0絶対除外**=実在未成年(加工有無問わず)・実名AV女優/実写成人素材・成人板(bbspink)・誹謗中傷/個人特定。中傷は事実エピソードだけ拾い、中傷文はそのまま使わない。
- ★r.jina.ai へ渡すのは**取得対象URLだけ**(local内の機微・持ち物を本文へ載せない)。
- ★**測った数字だけ**書く(記事本数・コメント件数・道具が出した削減率・保存パス)。取れなければ「取れなかった」と正直に。

## 依存
標準ライブラリ + `requests` のみ(bs4/readability 不要)。無ければ `pip install requests`。

## 完了の言い方
蒸留して保存しただけなら数(件数・削減率・パス)で報告する。「トークンが減った」と語るなら**道具が出した削減率の実値**を添える(§4.55=測っていない効果を語らない)。
