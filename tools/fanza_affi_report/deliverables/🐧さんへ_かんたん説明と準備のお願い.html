むずかしい設定は、ぜんぶこちらでやります

☃️これは何?

🐧さんのパソコンにそっと入れておくと、毎朝じどうで FANZA / DMMアフィリの売上を見に行って、ひとつの表(レポート)にまとめてお届けする道具です。

🐧さんがすることは ほとんどありません。 AIやパソコンの細かいことは、まったく分からなくて大丈夫です。むずかしいところは全部こちらで組みます。

✨使うときは、これだけ

1

最初に1回だけ、いつもの画面でログインかんたん

いつも売上を見ている画面に、いつも通りログインするだけ。パスワードを新しく作ったりはしません。

2

あとは毎朝、かってにレポートが届く

パソコンをつけておけば、決まった時間に自動でまとめて送ります。🐧さんの操作はいりません。

3

たまに「ログインし直してね」と出たら、ワンクリック

安全のため、時々ログインが切れます。そのときだけ、いつも通りもう一度ログインしてください(年に数回くらい)。

つまり ―― 最初のログインだけ 🐧さんにお願い。あとはおまかせでOKです。

🧊準備のために、教えてほしいこと

下の5つを教えてください。 むずかしく考えず、画面の写真(スクショ)を撮って送るだけでも大丈夫です。 分からないものは「わからん」でOKです。

1

いつも売上を見ている画面のアドレス

その画面を開いて、上の「https://…」のところをコピーして貼るか、画面のスクショを1枚。

2

ログインのしかた

ログインするとき、毎回スマホにSMSの数字が来たり、パスワードを聞かれたりしますか? それとも一度入れば、しばらくそのまま入れますか?

3

売上の表(CSV)を保存するボタンの画面

売上を「ダウンロード / CSVで保存」するボタンがある画面を、スクショで1枚。そのページのアドレスも一緒に。

4

使っているパソコンとブラウザ

Windows ですか? Mac ですか? いつも使うのは Chrome / Edge / Safari のどれ?

5

レポートの届け先

毎朝のレポートは、どこに届くと嬉しいですか?(例:このチャットに / メールに など)

🛡️安心してください

  • パスワードは 🐧さんのパソコンの中だけにあります。こちらには送られません。
  • この道具は 売上を見て、まとめて届けるだけ。勝手に何かを買ったり、投稿したりはしません。
  • うまく取れなかった日は、だまって放置せず 「今日はうまく取れませんでした」とちゃんとお知らせします。

分からないことは、遠慮なく「わからん」で大丈夫です 🐧

写真を送るだけでも、こちらで読み取って進めます。ゆっくりで大丈夫です。
